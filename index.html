cc-connect-installer

Claude Code + 飞书机器人，支持 6 家 LLM 服务商预设与自定义 URL；飞书默认 WebSocket 长连接，无需公网域名

🌐 默认托管在 GitHub raw：页面中的脚本地址指向本仓库的 raw 地址；若你已 fork，请把地址换成你自己的 raw 地址。

🚀 一行安装（推荐 Kimi Code：代码/长上下文场景）

非 TTY 服务器上直接复制粘贴执行，把 xxx 换成真实密钥：

  • CC_PROVIDER: LLM 服务商，这里用 kimi；可选 deepseek / glm / minimax / openrouter / anthropic / custom
  • CC_API_KEY: 对应服务商的 API Key
  • FEISHU_APP_ID / FEISHU_APP_SECRET: 飞书机器人凭证
  • -E 保留环境变量；sudo 用于写 systemd 服务与 npm 全局包；-fsSL 静默下载并跟随跳转
支持 Ubuntu / Debian / RHEL / Arch / macOS / WSL2

💡 原生 Windows 无法直接运行本 bash 脚本，建议通过 WSL2 安装；cc-connect 本体为 Node.js，也可在 Windows 上手动 `npm install -g cc-connect` 后自行配置。

交互模式

curl -fsSL https://raw.githubusercontent.com/ZACKLZ/cc-connect-installer/main/install-cc-connect.sh -o /tmp/inst.sh
bash /tmp/inst.sh

✨ Pro 版特性

🤖 多 LLM 预设 6 家主流服务商 + 自定义 OpenAI/Anthropic 兼容端点，一键切换。
⚡ 双模式安装 环境变量一行命令安装，或交互式菜单输入，服务器/本地都方便。
🔒 安全默认 API Key 使用 ${VAR} 占位符，由 systemd 注入；支持 allow_from 白名单。
🔄 模型切换 生成 [[providers.models]]，聊天中随时 /model switch 切换。
⏰ cron reuse 模式 默认 [cron] session_mode = "reuse"，避免定时任务推送丢消息。
🔌 飞书 WebSocket 长连接 默认长连接接收事件，无需公网 IP / 域名 / SSL，本地或内网服务器也能用。
🍎 跨平台 Ubuntu/Debian/RHEL/Arch/macOS 全支持，自动检测系统并安装 Node.js 22；Windows 推荐 WSL2，也可手动 npm 安装。
